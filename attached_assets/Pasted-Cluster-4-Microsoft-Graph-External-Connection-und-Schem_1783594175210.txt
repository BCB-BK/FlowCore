Cluster 4 – Microsoft Graph External Connection und Schema für Copilot Studio
Ziel

FlowCore erzeugt eine Microsoft Graph External Connection, deren Inhalte in Microsoft Search indexiert und in Copilot Studio als Enterprise data using connectors nutzbar werden.

Zu bauen

ExternalItem-Struktur

Jedes FlowCore-Item wird als Microsoft Graph externalItem abgebildet.
